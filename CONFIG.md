# Настройка фона (lw/config.js)

Всё крутится в одном файле — `lw/config.js`. Это обычный текстовый список
`ключ = значение`, правится блокнотом, пересобирать ничего не надо:

```
profile = ace       # ace | nano | still | low | medium | off
fps = 20
pixels = 3          # делитель разрешения: 3 => буфер 213x160
light = 120         # шаг смены освещения, секунд
fullscreenOnTap = 1 # первый тап — во весь экран
lock = 0            # 1 = файл главнее рычагов на телефоне
```

Приоритет: **дефолты -> lw/config.js -> рычаги на телефоне (если `lock = 0`) -> параметры URL**.
Неизвестные ключи и опечатки просто игнорируются — фон не упадёт.

## Профили

Цифры замерены на живом Samsung Galaxy Ace GT-S5830, Firefox 31, каждый прогон по несколько минут.

| профиль | буфер | fps факт. | мс/кадр | комментарий |
| --- | --- | --- | --- | --- |
| `nano` | 160x120 | ~29 | ~6 | максимальный запас, картинка грубее |
| `ace` | 213x160 | ~20 (19 на самой тяжёлой) | ~10 (11) | **дефолт**, лучший баланс |
| `low` | 320x240 | ~15 | — | красивее, запаса мало |
| `still` | 213x160 | — | — | только свет, без анимации |
| `off` | — | — | — | фона нет вообще |
| `high` | 640x480 | — | — | **НЕ ВКЛЮЧАТЬ**: телефон ушёл в перезагрузку через пару секунд |

`high` убран из панели рычагов и из стенда; достать его можно только вручную
(`profile = high` или `?lw=high`).

## Страницы

| файл | что это |
| --- | --- |
| `index mini.html` | оригинал SmartHome, **не тронут байт в байт** |
| `index minia.html` | та же страница + фон Living Worlds (62 добавленные строки) |
| `lw-tune.html` | стенд: все рычаги, АВТОТЕСТ, выбор сцены и времени |
| `lw-test.html` | минимальная проверка движка без SmartHome |

Пересобрать/снять фон:

```
node tools/install-mini.js                        # index mini.html -> index minia.html
node tools/install-mini.js --sync                 # пересобрать после правок оригинала
node tools/install-mini.js 'index minia.html' --check
node tools/install-mini.js 'index minia.html' --uninstall
```

## На телефоне

- **Долгое нажатие (1 с) на часы** — панель рычагов. Когда она открыта,
  рендер сам падает до `uiFps` (6), чтобы меню скроллилось.
- Кнопка **«Из конфига»** — забыть всё, что накручено руками, и вернуться к `lw/config.js`.
- Кнопка **«Во весь экран»** или `fullscreenOnTap = 1`.
- Фон живёт только на главном экране; на остальных таймер остановлен.

### Фуллскрин в Firefox 31

В старом Firefox кнопки «во весь экран» нет, но API есть (`mozRequestFullScreen`).
Если не срабатывает — `about:config`:

```
full-screen-api.enabled = true
full-screen-api.allow-trusted-requests-only = false
```

Фуллскрин сбрасывается при каждой перезагрузке страницы — поэтому и сделан `fullscreenOnTap`.

## Параметры URL (разово, без правки файла)

`?lw=nano` `?lwfps=15` `?lwscale=4` `?lwtod=120` `?lwblend=0` `?lwdirty=1`
`?lwanim=0` `?lwfit=cover` `?lwfs=1` `?lwdebug=1`

## Про АВТОТЕСТ

Колонка `максFPS` — это только счёт палитры и заполнение буфера.
Растяжка буфера на экран и композитинг UI — работа браузера, и на Ace она
стоит в несколько раз больше. Поэтому есть колонка `~реал` — те же цифры,
поделённые на 6 (коэффициент взят из реального замера: стенд обещал 122 fps
на ÷3, страница держала ~20). Ориентируйся на `~реал`.

## Аудио

Звука нет нигде: `audio/*.mp3` в сборку не попадают, объекты `Audio` не создаются,
элементов управления звуком в UI нет.
